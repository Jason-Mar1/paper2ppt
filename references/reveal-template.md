Use this template during Step 2 after the user approves the outline/style checkpoint, or immediately when the user explicitly asks to directly generate a reveal.js, HTML slides, webpage PPT, browser-based paper presentation, or visual academic paper talk page.

Default visual style for HTML PPT requests:

- Blue-white academic theme.
- English-only slide text unless the user requests another language.
- Times New Roman for academic titles/body.
- Comic Sans MS for handwritten-style tags, callouts, arrows, and short annotations.
- Actual paper figures when available.
